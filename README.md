## About

Hey, I am Faizan.

I am a software engineer at [Atlan](https://atlan.com). I build and maintain connectors that pull metadata into Atlan from SQL databases, BI tools, and other sources: PostgreSQL, Trino, AWS Glue, Monte Carlo, and more. I contribute to the [Atlan Application SDK](https://github.com/atlanhq/application-sdk) that those connectors run on, mostly around Dapr and Temporal integration, object storage, and security.

Earlier at Atlan I built the SDK's toolkit standard, the thing that says what a connector app declares, how it is validated before it runs, and how it keeps working in production.

Most of my work at Atlan is public through my work account, [@fyzanshaik-atlan](https://github.com/fyzanshaik-atlan).

Outside work I build developer tools and small versions of systems I want to understand. Right now that means AI agents, distributed systems, low-level programming, language runtimes, and machine learning.

## Projects

Some things I have built:

- [cachewatch](https://github.com/fyzanshaik/cachewatch), a native macOS menu bar monitor for Claude Code sessions.
- [dirgo](https://github.com/fyzanshaik/dirgo), a CLI and MCP server that generates compact project context for developers and AI agents.
- [BookMyEvent](https://github.com/fyzanshaik/bookmyevent-ily), a concurrent event-booking backend in Go, with PostgreSQL, Redis, and Elasticsearch.
- [mini-git](https://github.com/fyzanshaik/mini-git), a small Git implementation written to understand repositories, staging, commits, and object storage.
- [Garbage Collection Simulator](https://github.com/fyzanshaik/mark-sweep-trace-garbage-collector), a mark-and-sweep tracing garbage collector written in C.
- [Gork](https://github.com/fyzanshaik/gork-code), an experimental coding-agent CLI built around model function calling.
- [LinkLens](https://github.com/fyzanshaik/linklens-extension), a Chrome extension for previewing links without leaving the current page.
- [LeetFetch](https://github.com/fyzanshaik/leetfetch), an interactive explorer for LeetCode's GraphQL API.
- [Pluto](https://github.com/fyzanshaik/pluto), a static-site generator written in Python.
- [Gator](https://github.com/fyzanshaik/gator-fetch-rss-feeds), a command-line RSS aggregator backed by PostgreSQL.

There are older apps, extensions, CLI tools, and experiments on this account too. They are not how I build today, but they are how I learned.
