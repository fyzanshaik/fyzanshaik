## About

Hey, I am Faizan.

I am a software engineer at [Atlan](https://atlan.com). I work on developer infrastructure for building and running data applications. Most of my work at Atlan is public through my work account, [@fyzanshaik-atlan](https://github.com/fyzanshaik-atlan).

I work primarily on the [Atlan Application SDK](https://github.com/atlanhq/application-sdk), a Python toolkit for building applications and data connectors on the Atlan platform. It handles application configuration, credentials, workflow orchestration, metadata extraction, storage, observability, and the path from local development to production.

My work there includes the native application contract system, pre-run source and configuration validation, runtime reliability, Dapr and Temporal integration, object storage, security, conformance testing, and developer tooling. I am one of the project's primary contributors and a code owner for the contract toolkit.

Outside work, I build developer tools and smaller implementations of systems I want to understand. I am currently interested in AI agents, distributed systems, low-level programming, programming language runtimes, and machine learning.

## Open source

Open source has been a major part of how I learned software engineering.

I have worked on [Hermes Agent](https://github.com/NousResearch/hermes-agent), an extensible personal AI agent built by Nous Research. My work has involved understanding and improving a large agent system across its conversation loop, tools, sessions, providers, desktop experience, and supporting infrastructure.

## Projects

I have built a lot of things while figuring out which parts of software engineering I care about most.

Some of them are:

- [cachewatch](https://github.com/fyzanshaik/cachewatch), a native macOS menu bar monitor for Claude Code sessions.
- [dirgo](https://github.com/fyzanshaik/dirgo), a CLI and MCP server for generating structured, token-aware project context for developers and AI agents.
- [BookMyEvent](https://github.com/fyzanshaik/bookmyevent-ily), a concurrent event-booking platform built with Go, PostgreSQL, Redis, and Elasticsearch.
- [mini-git](https://github.com/fyzanshaik/mini-git), a small Git implementation written to understand repositories, staging, commits, and object storage.
- [Garbage Collection Simulator](https://github.com/fyzanshaik/mark-sweep-trace-garbage-collector), a mark-and-sweep tracing garbage collector written in C.
- [Gork](https://github.com/fyzanshaik/gork-code), an experimental coding-agent CLI built around model function calling.
- [LinkLens](https://github.com/fyzanshaik/linklens-extension), a Chrome extension for previewing links without leaving the current page.
- [LeetFetch](https://github.com/fyzanshaik/leetfetch), an interactive explorer for LeetCode's GraphQL API.
- [Pluto](https://github.com/fyzanshaik/pluto), a static-site generator written in Python.
- [Gator](https://github.com/fyzanshaik/gator-fetch-rss-feeds), a command-line RSS aggregator backed by PostgreSQL.

There are many earlier applications, browser extensions, command-line tools, and experiments on this account. They do not all represent how I build today, but they document how I learned.
